# Rendered previews

Latest renders of the Patel Bakery 60-second film, with the official logo and the original
soundtrack. They're compressed for easy sharing. For full quality, run `npm run render:all`
(output goes to `out/`).

| File | Format | Use |
|---|---|---|
| `patel-bakery-intro-16x9.mp4` | 1920×1080 | Website, YouTube, displays, presentations |
| `patel-bakery-intro-9x16.mp4` | 1080×1920 | Instagram Reels, YouTube Shorts, Stories |
| `patel-bakery-intro-1x1.mp4` | 1080×1080 | Instagram and Facebook feed |

Heritage and product photos are still marked placeholders until real photos are supplied.
